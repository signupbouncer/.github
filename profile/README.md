# SignupBouncer

SignupBouncer is an API that checks new signups for disposable emails, Gmail aliases and repeat accounts. Each check answers allow, challenge or block, with a score and the reasons.

It installs as a Supabase auth hook with no code, as a Better Auth hook, or as one HTTP call from any backend.

- Website: https://signupbouncer.com
- Docs: https://signupbouncer.com/docs
- Free disposable email checker: https://signupbouncer.com/disposable-email-checker
- MCP server: https://signupbouncer.com/mcp
- For AI assistants: https://signupbouncer.com/llms.txt

## Repositories

- [burner-domains](https://github.com/signupbouncer/burner-domains): a disposable email domains list, updated daily, CC0.
- [nextjs-saas-starter-signup-protection](https://github.com/signupbouncer/nextjs-saas-starter-signup-protection): block disposable emails and repeat accounts in the Next.js SaaS starter.
- [nextjs-supabase-ai-image-credits](https://github.com/signupbouncer/nextjs-supabase-ai-image-credits): an AI image generator on Next.js and Supabase whose free credits hold up against disposable and repeat signups.
